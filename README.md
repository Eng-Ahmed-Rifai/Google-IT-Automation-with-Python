## 🛠️ Skills & Technologies Covered
- **Core Python Programming**: Functions, loops, recursions, data structures (strings, lists, dictionaries), object-oriented programming (OOP).
- **Operating System Automation**: Interacting with files, processes, subshells, environment variables, regex data parsing.
- **Version Control & Collaboration**: Git branching, merging, remote management with GitHub, resolving merge conflicts.
- **Debugging & Performance Optimization**: Memory profiling, CPU bottlenecks, systematic troubleshooting, root cause analysis.
- **Cloud & Configuration Management**: Puppet automation, Infrastructure as Code, deploying virtual instances in Google Cloud.
- **Real-World IT Automation**: PIL image processing, REST APIs, JSON serialization, automatic PDF reporting, and automated email dispatch with attachments.
